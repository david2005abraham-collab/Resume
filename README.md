## 🚀 Quick Start & Deployment

### Local Development
To view the portfolio locally:
1. Double-click `index.html` to open directly in your web browser.
2. Or run a lightweight local HTTP server:
   ```bash
   python -m http.server 8080
   ```
   Then open `http://localhost:8080` in your browser.

### Deploying to GitHub Pages
1. Push to GitHub:
   ```bash
   git push origin main
   ```
2. In GitHub repository settings, go to **Pages** > select **Deploy from a branch** (`main` / root) to publish live instantly!
